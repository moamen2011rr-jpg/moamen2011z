# Smart Prayer Times — Android Native

مشروع Kotlin/Jetpack Compose/Material 3 أصلي. يستخدم DataStore، Fused Location Provider، WorkManager، Android AppWidget، وBroadcastReceiver. الحساب محلي ويعمل دون إنترنت بعد تحديد الموقع.

افتح المجلد في Android Studio ثم نفّذ `assembleDebug`. البيئة الحالية لا تحتوي Android SDK أو Gradle، لذلك لم يتم إصدار APK داخل هذه الجلسة.
